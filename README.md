A single 192-character sentence recalling a childhood memory: August evenings, Grandma calling us in from the yard, rice steaming on the stove, and her voice in the screen door's squeak whenever summer rain starts to fall. It writes the memory to `/output/entry.txt` for the AI judge to compare against other childhood memories.

## Run it

```sh
python3 main.py
```
